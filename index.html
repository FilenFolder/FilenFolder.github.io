About the Studio

Who we are and how we approach our work.

FilenFolder Studios began as a way to turn side projects into finished, publishable products. Over time it has grown into a broader practice that covers interactive entertainment, utility software, and the websites and interfaces that support them.

We work across disciplines on purpose. A game benefits from good tooling, a tool benefits from good interface design, and a website benefits from the discipline of game development, where performance and responsiveness are not optional. Working in all of these areas keeps our skills sharp and our projects consistent.

Most of our projects begin as small, focused experiments. The ones that prove their value are refined, documented and released publicly, and where it makes sense, we publish the source code so others can learn from it.

What We Specialize In

Core areas of development and the standards we hold ourselves to in each of them.

Game Development

Complete game production from prototype to release, including movement and physics systems, level design, input handling and publishing on itch.io.

Desktop Software

Utilities and tools with clear graphical interfaces, built to solve a specific problem well and to be easy to install, understand and use.

Web Development

Responsive, accessible websites written in clean HTML5 and CSS3, with JavaScript added only where it improves the experience.

UI / UX

Interface design focused on legibility, consistent navigation and predictable behavior, so that people can use a product without needing instructions.

Experimental Tech

Research-driven prototypes that test new ideas, tools and workflows. Not every experiment ships, but each one informs the work that follows.

How We Work

Every project follows the same four stages, regardless of size.

  1. Concept and Planning

    We define the goal, the audience and the scope before any code is written. A clear scope is the most reliable way to finish a project.

  2. Prototype

    We build the smallest working version of the core idea first, then test whether it is worth developing further.

  3. Build and Refine

    The prototype is expanded into a complete product, with regular playtesting or user testing guiding each iteration.

  4. Release and Maintain

    We publish, gather feedback and fix issues. If a project reaches the end of its life, we say so openly and mark it as shut down.

Our Principles

The standards behind every release.

Quality First

We would rather release fewer projects that work properly than many that do not.

Transparency

We state clearly what each project is, what technology it uses and whether it is still supported.

Original Work

Our programs, games, animations and artwork are created in-house and credited to the people who made them.
